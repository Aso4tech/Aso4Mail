# Aso4Mail (C# / WPF)

Experimental Windows business email client for existing cPanel/WHM mailboxes. This is a **source-only, unverified test build**, not a security-certified release. GitHub Actions builds an unsigned Windows artifact for testing. No Rust, Tauri, background notifications or Windows autostart.

See `README_AR.md` for Arabic instructions. Never commit credentials, account files, private messages, or old flagged executables. Review the source and NuGet dependencies and scan the final EXE before use.
