# Aso4Mail C# / WPF — نسخة تجريبية

هذا مشروع تجريبي **غير معتمد أمنياً**، جديد، ولا يستخدم Rust أو Tauri أو إشعارات Windows أو التشغيل التلقائي.
بريد cPanel IMAP 993 / SMTP 465 مع TLS، عرض آخر 70 رسالة، بحث محلي في القائمة، إرسال ورد، مرفقات حتى 50 MiB، توقيع نصي لكل حساب وتحديث كل 30 ثانية ما دامت النافذة مفتوحة.

## الحصول على EXE
افتح GitHub Actions > Build Aso4Mail Windows (unverified test) > Run workflow.
بعد النجاح نزّل artifact باسم Aso4Mail-Windows-x64-UNVERIFIED. هذا الملف اختبار فقط وليس إصداراً تجارياً.

## تنبيهات مهمة
- لا ترفع كلمات مرور أو ملفات البريد أو ملفات EXE القديمة.
- العرض نصي ولا ينفذ HTML خارجي.
- تخزن حسابات البريد مشفرة محلياً باستخدام Windows DPAPI لحساب مستخدم Windows، لا في GitHub.
- الوظائف غير المكتملة: حفظ Sent والمجلدات والأرشفة وجهات الاتصال وصور التواقيع والتقويم.
- قد يكون حد سيرفر البريد أقل من المرفقات بعد زيادة الحجم بواسطة MIME.
- لم يتم اختبار تجميع التطبيق أو أمان الملف التنفيذي على Windows بعد. راجع نتيجة GitHub Actions ثم افحص الملفات في Defender قبل التجربة.
