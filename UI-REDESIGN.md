# Aso4Mail Outlook-inspired WPF redesign

This experimental branch replaces the primitive UI with a more professional black-and-gold three-pane shell: branded top header, search, left navigation, message list with sender/subject/time, and a reading pane. IMAP and SMTP functions are unchanged.

**Important:** Only Inbox is implemented. Sent/Drafts/Archive/Junk/Trash are visually labeled as coming soon, not interactive. The UI is not a 1:1 Outlook clone. This is an unverified test build, not approved for company use.
